# Eder — Editorial Landing Page

A single-page, responsive product website for Eder, redesigned with editorial typography, numbered navigation, and a focused storytelling layout inspired by the structure of provingislam.com. The original Eder identity and real app screenshot are retained.

## Preview
Open `index.html` in your browser. No build step needed.

## Deploy to GitHub Pages
Publish the contents of this directory from the root of your GitHub Pages repository, or copy it into `/docs` in the Eder repo and select that folder in GitHub Pages settings.

## Before publishing
- The "Get Eder" section links to the Eder 0.1.0 Linux x86-64 AppImage and GitHub repository.
- Confirm system requirements and supported platforms for future releases.
- Replace `assets/eder-app.webp` with an updated screenshot when the UI changes.

The website works without JavaScript except for its mobile menu and entry transitions. Google Fonts are optional; local fallback fonts work offline.
